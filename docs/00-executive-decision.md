# 00｜执行决策

## 结论

FM 不需要立刻换成一个完全不同的商业模式，但必须**换购买理由**。

### 旧购买理由

“输入一个想法，FM 会替你生成故事、歌曲和视频；背后有多个模型、MCP 和不同模式。”

这部分会被 ChatGPT、Higgsfield、H3/H3 Max 以及更多 wrapper 快速压平。隐藏模型复杂度是正确的 UX，但它不是防御性资产，因为竞争者也能隐藏。

### 新购买理由

“**我的创作世界不会在下一次生成时失忆。** FM 在花费较高成本前告诉我会遵守什么；生成完成后，我可以决定哪些事实、角色状态和参考资产进入自己的 World。”

这不是“更会画角色”的承诺，而是**可复用、可确认、可追溯的创作状态**。

## FM 的新产品定义

| 层 | 用户看到的东西 | FM 内部承担的职责 |
|---|---|---|
| World | 一个长期存在的世界，如 `LAMO HEL` | 组织实体、版本、关系、时间线与资产权限 |
| Canon | 用户批准的事实 | 事实状态、来源、适用时间与冲突检查 |
| Reference Set | 当前批准使用的图片、声音、动作、风格 | 把多个资产编译成模型可理解的参考包 |
| Creative Contract | 本次生成前的短确认 | 锁定硬约束、允许变化、输出规格与最高估算 |
| Generation | 一次可计费的生成事件 | 预估、预留、执行、验证、结算与审计 |
| Scratch | 不想建世界时的快速入口 | 低摩擦尝试、可见 TTL、手动提升到 World |

## 为什么不是另一个“World 文件夹”

H3 已经可以在一次请求中携带多张图片、视频和音频参考；只做角色盒子、素材库和“保存到 World”开关，会成为 H3 的资产管理外壳，容易被复制。

真正有价值的区别是：

1. 角色有稳定 ID、版本和状态，而不是一张当前图片。
2. Canon 事实有 `proposed / accepted / rejected / superseded` 状态，并保留来源。
3. 关系有方向、时间和变化历史，例如“已结盟”后来变为“互不信任”。
4. 每次昂贵生成前都可查看“本次必须遵守什么、什么允许变化、最高可能花费多少”。
5. 输出引用了哪些实体版本和参考集；用户接受后才决定是否更新 World。
6. 换 H3、H3 Max、其他图片/文本/视频模型时，World 仍然属于用户。

## 目标客户顺序

### 第一楔子：独立连载创作者（B2C）

他们不是只想要一次好看的图，而是需要持续发布同一批角色和设定。先服务已有连载、短篇系列、世界观项目，并不先服务所有“想做一个视频”的大众。

### 第二楔子：小型营销/创意团队（B2B）

在 B2C World Beta 的复用率、首次可接受率、失败率和毛利稳定后，再加入 Brand/Campaign 的共享资产、审批、角色权限和 ROI 报告。仍然是自助使用 FM，不承诺固定价格替客户无限试错。

## 经济模型决策

用户采用 BYOK 或 FM 代付，不改变核心问题：如果 FM 只是替用户调用 OpenRouter，用户会比较谁更顺手、谁更便宜。因此 FM 应隐藏供应商，同时让**最终可交付的生成事件价格透明**。

本方案的实际选择是：**FM 继续代付并管理自己的 OpenRouter/provider 调用，不在 v1 推 BYOK**。用户不承担模型接入复杂度，但能在生成前看到最高估算、在完成后看到实际结算。

建议公式：

```text
最高估算 = 供应商成本上限
        + FM 编排/验证费
        + 存储与传输费
        + 明示的风险缓冲

开始前：原子预留最高估算
完成后：按真实 provider usage.cost + 已声明费用结算
差额：释放回余额
技术上无可用结果：不收费或退款
文件可用但主观不喜欢：不退款，可用低成本 Preview 再试
```

这不是固定价代制作。用户仍在 FM 内自己决定 Prompt、参考集、Preview、Final 和是否提升到 World。

## 成功标准

World Beta 不是上线更多按钮，而是验证以下行为：

| 指标 | 初始判断门槛，待实验校准 |
|---|---:|
| 第一次生成中引用至少一个既有实体/参考集的比例 | > 35% |
| 7 日内同一 World 的再次生成率 | > 30% |
| 使用 Contract 后的首次可接受率相对 Scratch 的提升 | 相对提升 > 15% |
| 技术失败但被收费的事件 | 0 |
| 被接受资产在后续生成中再次引用的比例 | > 25% |
| 每个接受 Final 的平均尝试成本 | 连续 4 周下降 |

这些是**实验门槛，不是市场事实**。如果用户不重复使用、也不愿确认 Canon，那么 FM 应保留为优秀的 Scratch 工具，而不是强行建设重型 World 平台。

## 最终判断

- 当前 FM 作为“多模型提示词到媒体生成器”：战略差异正在迅速下降。
- 只有 World 文件夹和角色素材盒：差异仍不足。
- World + Canon + 关系状态 + Contract + 版本来源 + 可结算生成事件：仍有可能成为防御性产品，但现在只是待验证假设。
- H3/H3 Max 不是要躲避的敌人，而是让 FM 更便宜、更快、更适合作为执行器的基础设施。
